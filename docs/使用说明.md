# Danus 桌面版使用说明（Windows + DeepSeek）

这是一套把 Danus（AI 数学证明搜索系统）改造成 Windows 原生软件后的版本：
双击 `启动Danus.bat` 即可打开网页界面，全程点击操作。

## 第一步：装环境（只做一次）

1. 安装 Python 3.10+（[python.org](https://www.python.org/downloads/)），安装时勾选
   “Add python.exe to PATH”。如果已装 Node.js 更好（没有也没关系，界面里可一键装）。
2. 双击 `启动Danus.bat`。首次运行会自动创建虚拟环境并安装依赖（1~3 分钟）。
3. 浏览器会自动打开界面（http://127.0.0.1:8765）。

## 第二步：配置 DeepSeek

1. 打开「设置」页：填入 DeepSeek API Key（platform.deepseek.com 申请，sk- 开头）。
   - worker/验证模型：`deepseek-v4-flash`（Codex 走的 Responses API，目前只有它支持）
   - 策略咨询模型：`deepseek-v4-pro`（可选，Chat API 通用）
2. 点「保存设置」。
3. 到「总览」页：点「检测环境」→「写入 DeepSeek 配置」→「测试 DeepSeek 连接」（应显示 ok）。
4. 如果提示未找到 Codex CLI：点「安装 Codex CLI」，等日志结束再「检测环境」。

## 第三步：跑一个数学问题

1. 「总览」页点「启动验证服务」（状态变绿）。**不启动验证服务，任何事实都不会被接受。**
2. 「项目」页新建项目：英文项目名 + 选择 worker 数量 + 粘贴你的数学问题/猜想，点「创建项目」。
3. 点项目卡片进入工作台：
   - 给每个 worker 填「本轮任务」（或点「生成策略指引」让 DeepSeek 帮你分解问题，
     再点「按条目分配到 Worker」）。
   - 点「全部启动」。worker 会开始自动证明：读任务 → 搜索已有事实 → 尝试证明 →
     提交给验证器 → 通过则写入事实图 → 下一轮继续。
4. 「事实图」页实时查看所有已验证结果（statement/proof/依赖关系）；发现错误可撤销（级联）。

## 常见问题

- 验证服务起不来？看 `runtime/logs/verify.log`；多半是 Codex CLI 未装或配置没写入。
- worker 一直不产出事实？先确认「总览」验证服务是绿的；再在 worker 卡片点「日志」。
- 想省钱/省时间：新建项目时选 `1 普通 + 1 高`，或给项目设置截止时间（工作台）。
- 本软件自动读取/写入的所有数据都在本文件夹的 `runtime/` 目录下，删除即全部清空。

## 使用 OpenCode Go 套餐（DeepSeek V4 Flash / Pro）

1. 打开 https://opencode.ai/zen 登录并订阅 OpenCode Go（$10/月），复制你的 API Key。
2. 在软件「设置」页把「提供商」选为 **OpenCode Go 套餐**（Base URL 会自动填 https://opencode.ai/zen/go/v1）。
3. 把 API Key 换成 OpenCode Zen 的 Key，点「保存设置」。
4. 到「总览」点「写入 DeepSeek 配置」→「测试连接」→「启动验证服务」，然后正常建项目跑 worker。
5. worker/验证器/策略咨询都会走你的 Go 套餐额度：DeepSeek V4 Flash 约 3.1 万次/5 小时、V4 Pro 约 3400 次/5 小时（以官方额度表为准）。
